🍎 Blog de Frutas
Um blog simples desenvolvido com HTML e CSS puro, dedicado a compartilhar informações sobre frutas essenciais no dia a dia.
O objetivo do projeto é praticar desenvolvimento web básico enquanto apresento conteúdos sobre alimentação natural e frutas importantes para a saúde.

🌐 Acesse o projeto
🔗 https://mr-keyer.github.io/blog-frutas/

📌 Sobre o projeto
Este blog apresenta artigos sobre frutas consumidas diariamente, explicando:
Benefícios para a saúde
Nutrientes importantes
Curiosidades sobre as frutas
Importância na alimentação diária
O projeto foi criado como prática de estruturação de páginas web e estilização com CSS.

🛠️ Tecnologias utilizadas

HTML5
CSS3

🎯 Objetivo do projeto
Praticar estrutura de páginas web
Melhorar habilidades em HTML e CSS
Criar um blog simples e funcional
Publicar conteúdo educativo sobre frutas
